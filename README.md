# The 3AM Fridge Text

A make.fun one-line entry: the one line a smart fridge would text its owner
at 3am. The entry is a single line of 1 to 140 characters, written by
`main.py` to `/output/entry.txt`, where the competition's sealed scorer reads
it. An AI judge then compares entries two at a time and keeps the funniest
one.

Competition: https://make.fun/api/competitions/u-deysumbrella-the-3am-fridge-text-4c3e721d/requirements

## Entry

It's 3am. The leftover pizza has formed a union and is demanding to be eaten before it expires.
